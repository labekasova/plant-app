# Plant App — v0.3

Небольшой двуязычный трекер ухода за растениями. Данные сохраняются локально в браузере; сервер и регистрация для MVP не нужны.

## Возможности

- отдельная стартовая полка в каждой зоне;
- неограниченное количество растений: новые полки появляются автоматически;
- отдельные визуальные зоны для домашних и уличных растений;
- пять авторских SVG-типов растений;
- выбор расположения и интервала полива;
- индикатор, когда растение пора полить;
- заметки, полив и удаление растения;
- переключение RU/EN;
- переключаемая тёплая тёмная тема с луной и звёздами;
- автоматическое уменьшение шрифта для длинных имён на горшках;
- широкие горшки, на которых полностью видны имена до 15 символов;
- адаптивный интерфейс и поддержка `prefers-reduced-motion`.

## Локальный запуск

```bash
npm install
npm run dev
```

Производственная сборка:

```bash
npm run build
npm run preview
```

## GitHub Pages

Проект настроен для репозитория `plant-app` и адреса:

`https://labekasova.github.io/plant-app/`

После загрузки файлов откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**. Workflow `.github/workflows/deploy.yml` будет публиковать приложение после каждого push в `main`.

Если имя репозитория изменится, обновите `base` в `vite.config.js`.
